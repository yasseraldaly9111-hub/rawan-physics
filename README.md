# منصة فيزياء الأستاذة روان محمد — نسخة Firebase

في هذه النسخة **لا توجد أي بيانات داخل ملفات الموقع**. كل البيانات محفوظة في قاعدة بيانات Firebase (Cloud Firestore):

| البيانات | مكانها في Firestore |
|---|---|
| شرح الفصول والتمارين والأسئلة الوزارية | `chapters` |
| أسماء المشاركين في الدرس (لكل صف) | `participants/1` و `participants/3` |
| التبليغات | `announcements` |
| إعداد السماح بالمراسلة | `settings/site` |
| رسائل الطلاب وردود الأستاذة | `inbox/{رقم الطالب}/msgs` |
| الملزمة PDF (للأستاذة فقط) | `private_files/malzama` |

أما ملفات `public/` فهي التصميم والبرمجة والتجارب فقط.

## محتويات المجلد
- `public/` : ملفات الموقع التي تُرفع على Firebase Hosting.
- `public/firebase-config.js` : إعدادات المشروع وبريد المالك (معبّأة مسبقًا لمشروع rawan-physics).
- `firestore.rules` : قواعد الحماية (من يقرأ ومن يكتب).
- ملفا المادة والملزمة **ليسا في المستودع**؛ يُرفعان من لوحة التحكم إلى قاعدة البيانات.

## التشغيل والنشر
المشروع مربوط مسبقًا بمشروع Firebase ‏`rawan-physics` (الإعدادات في `public/firebase-config.js` و `.firebaserc`).

**النشر تلقائي من GitHub:** كل دفع (push) إلى الفرع `main` يشغّل الملف `.github/workflows/firebase-deploy.yml`
الذي ينشر الموقع وقواعد الحماية (`firestore.rules`) على Firebase. يحتاج مرة واحدة إلى:
- **Secret** باسم `FIREBASE_SERVICE_ACCOUNT`: محتوى ملف JSON لحساب خدمة (Service Account) بصلاحيتي
  *Firebase Hosting Admin* و *Firebase Rules Admin*.
- **Variable** باسم `FIREBASE_PROJECT_ID` بالقيمة `rawan-physics`.

(من المستودع: Settings ← Secrets and variables ← Actions). يمكن أيضًا تشغيل النشر يدويًا من تبويب Actions ← Deploy to Firebase ← Run workflow.

**النشر اليدوي (اختياري):** `npm install -g firebase-tools` ثم `firebase login` ثم `firebase deploy --only hosting,firestore:rules`.

**بعد أول نشر:**
1. افتح الموقع ← «دخول الأستاذة» أسفل الصفحة الرئيسية ← سجّل الدخول بحساب المالك.
2. من بطاقة «المادة الدراسية» ارفع ملف الفصول (`chapters-g3.json`)، ومن بطاقة «الملزمة PDF» ارفع الملزمة.
   هذان الملفان غير موجودين في المستودع عمدًا؛ يُحفظان في قاعدة البيانات فقط.
3. من «إدارة المستخدمين» أنشئ حساب الأستاذة بصلاحية «أستاذ/ة».

## الصلاحيات
| الصلاحية | ماذا تستطيع |
|---|---|
| **المالك** | كل شيء، وصلاحيته ثابتة لا تُلغى من الموقع |
| **مدير** | كل شيء + إنشاء المستخدمين وتغيير صلاحياتهم وإلغاؤها (عدا المالك) |
| **أستاذ/ة** | المشاركون، التبليغات، المراسلة، المادة، الملزمة PDF |

- إنشاء مستخدم: الاسم والبريد وكلمة المرور والصلاحية، ويبقى المدير مسجّلًا دون خروج.
- لمنح صلاحية لحساب موجود: اكتب بريده واترك كلمة المرور فارغة.
- «إلغاء الصلاحية» يمنع الحساب فورًا. حذف الحساب نهائيًا أو تغيير كلمة مرور شخص آخر يتطلبان خطة Blaze، والبديل زر «إعادة تعيين كلمة المرور» الذي يرسل رابطًا إلى بريد المستخدم.

## الاستعمال اليومي للأستاذة
من «لوحة الأستاذة»:
- **المشاركون في درس اليوم:** اختيار الصف، ثم كتابة الأسماء (كل اسم في سطر)، ثم «حفظ ونشر». تظهر في الواجهة الرئيسية فورًا.
- **التبليغات:** عنوان وتفاصيل، ولأي صف تظهر، مع خيار التثبيت في الأعلى.
- **السماح بالمراسلة:** مفتاح تشغيل وإيقاف. عند الإيقاف لا يستطيع أي طالب الإرسال، والمنع مطبّق في قواعد الحماية نفسها لا في الواجهة فقط.
- **رسائل الطلاب:** لكل طالب محادثة مستقلة، والرد يظهر للطالب مباشرة.

## الحماية
- الطلاب يقرؤون الفصول والتبليغات والمشاركين فقط، ولا يستطيعون تعديل أي شيء.
- كل طالب يرى محادثته فقط، ولا يستطيع انتحال رد الأستاذة.
- الكتابة في المحتوى محصورة بحساب الأستاذة المكتوب في `firestore.rules`.
- الملزمة PDF لا يقرؤها ولا ينزّلها إلا حساب الأستاذة، ولا يوجد لها رابط عام.

## ملاحظات
- يحفظ الموقع نسخة من البيانات على الجهاز، فيفتح بسرعة ويعمل عند انقطاع الإنترنت المؤقت.
- عند تجهيز مادة الأول المتوسط تُرفع بالطريقة نفسها كملف فصول بالحقل `"grade": "1"`.
- هذه البنية نفسها (Firestore + Authentication) هي التي سيستعملها تطبيق الطلاب على الهاتف لاحقًا.
